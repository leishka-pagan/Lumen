How this works

  1. Pick one of the nine claim types on the left. This is a claim the AI might make about a customer.
  2. Pick a case from the list below. Each claim type has one PASS example and one FAIL example.
  3. Read the customer profile and the transactions.
  4. Hit Verify. The deterministic Python check runs in the browser, exactly as it runs in the real system.
  5. Read the verdict and the trace. This is the verifier's actual logic, not an AI's opinion.
Reading the verdict: the verdict is about the AI's claim, not the customer. SUPPORTED means the records back up what the AI said. CONTRADICTED means the records do not back up what the AI said, so the AI's suspicion was wrong.
