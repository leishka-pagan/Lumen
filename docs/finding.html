THE FINDING

What we set out to check, and what we found

Every claim type carries a short description that goes into the AI's instructions. And every claim type carries a rule enforced in code by the verifier. We compared them, one by one.

Ninety-three claims across thirty-nine alerts. Thirty-two contradicted. Grouped by whether the model was told the rule it would be scored against, the pattern is stark: where the description matched the enforced rule, the model was right 45 times out of 45. Where the description withheld or differently stated the rule, the model was wrong 32 times in 48, roughly two thirds. The remedy this points to is not better phrasing. It is stating the enforced rule, with its threshold, in the description the model receives. prior_sar_history already does this. Its description names the table, the column and the operator, and it is the only description written in the verifier's own language.

WHAT IT MEANS

Why This Matters

Three takeaways from a finding that only strict verification could have surfaced.

1
The AI was not careless
It answered the question the prompt asked. When told "aggregate volume," it produced an aggregate. When told "similar amounts, same day," it looked for similar amounts on the same day. Both were consistent with their own instructions; the verifier scored a different rule.
2
The fix is not a smarter model
Where the description matched the code, the model was right 45 out of 45 times. The improvement is not more parameters or more training. It is stating the enforced rule, with its threshold, in the description the model receives. One description already does this. It carries a 0% contradiction rate.
3
One claim discriminates
The finding could also mean "the model is weak at computation." One claim type separates the two hypotheses: high_risk_country. It is set membership, a lookup rather than a calculation, and it still contradicts at 50% because the list of seven countries was never given to the model. That favors the definition-gap explanation.
4
Only strict checking makes this visible
If the verifier had been lenient or fuzzy, the gap would have been invisible. Because the check is deterministic, the disagreement between description and rule became measurable and fixable. This finding is a byproduct of the mechanism working, not a critique of it.
