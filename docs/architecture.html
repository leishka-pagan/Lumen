CLOSED VOCABULARY

The Nine Claim Types

The AI may only assert claims from this fixed list. It cannot invent a tenth. The list itself is generated from the verifier code, so no claim type can be offered unless a check exists for it. Click any card to see the rule.

structuring
Splitting deposits to avoid reporting
Two or more inbound deposits, each between $9,000 and $9,999, inside a 72-hour window.
rapid_movement
Money in and out fast
Three or more transactions inside 24 hours, with at least one inbound and one outbound, totalling over $10,000.
unusual_transaction_volume
Transaction exceeds expected activity
The largest single transaction exceeds twice the customer's stated expected monthly volume.
expected_activity_mismatch
Above the customer's own baseline
The largest single transaction exceeds the customer's stated expected monthly volume.
high_risk_country
Counterparty in a sanctioned jurisdiction
A transaction counterparty country is one of: IR, KP, SY, MM, CU, VE, RU.
prior_sar_history
Prior SAR on record
The customer has one or more Suspicious Activity Reports filed previously.
prior_alert_history
Customer has prior alerts on record
The customer has more than one alert on record. Note: the current alert counts, so exactly one alert (the one under review) fails; two or more passes.
missing_kyc_data
Required KYC record missing
One or more required KYC evidence items are marked unavailable.
stale_kyc_profile
KYC profile not refreshed in 12 months
The customer's KYC record is not current within the last 12 months.
DEFENSE IN DEPTH

The Seven Controls

Seven independent safeguards wrap the one AI step. Each catches a different kind of failure before it can reach the human reviewer.

1
Closed Claim Vocabulary
Nine claim types, generated from the verifier code. A type cannot be offered unless its check exists.
2
Structured JSON Output
The AI must respond in a fixed schema. No free-text prose that an analyst has to interpret.
3
Schema Enforcement
Pydantic v2 rejects malformed AI output before it ever reaches a verifier.
4
Deterministic Verifier
Nine Python functions return PASS, FAIL, or NEEDS_REVIEW. No AI judging AI.
5
Human Approval Gate
Enforced in code, not policy. A review is not complete without evidence confirmed, rationale written, and action taken.
6
Controlled Audit Vocabulary
Audit events use a fixed enum of action names. Unknown event names are rejected.
7
Examiner Replay
Every decision can be reconstructed from the audit trail years later, with the actor, action, and rationale on file.
